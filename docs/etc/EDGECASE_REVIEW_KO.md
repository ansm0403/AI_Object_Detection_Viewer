## Step 컨텍스트

```
STEP     : [예: Step 3 — 3D 뷰어 컴포넌트]
FILES    : [예: src/components/Viewer3D.tsx]
CONCERNS : [예: 대용량 데이터셋 렌더링, 메모리 정리]
SKIP     : [예: 보안, 접근성]
```

## 체크리스트

### 핵심 (항상 검사)
- [ ] Null / undefined / 빈 입력값 처리됨?
- [ ] 로딩 / 에러 / 빈 상태 UI 있음?
- [ ] 비동기 에러 catch됨? (try/catch, .catch)
- [ ] 언마운트 시 이벤트 리스너 / 타이머 정리됨?

### 데이터 & 상태
- [ ] 극단값 처리됨? (0, 음수, Infinity, NaN)
- [ ] 경쟁 조건 가능성? (동시 비동기 호출)
- [ ] 데이터 갱신 후 오래된 상태(stale state) 위험?

### UI
- [ ] 매우 길거나 짧은 콘텐츠에서 레이아웃 깨짐?
- [ ] 모바일 / 작은 화면에서 동작함?

### 시각화 (해당 없으면 건너뜀)
- [ ] 빈 데이터셋이 우아하게 렌더링됨?
- [ ] 데이터 포인트 1개일 때 올바르게 렌더링됨?
- [ ] 모든 값이 동일할 때 올바르게 렌더링됨?
- [ ] 언마운트 시 WebGL / 캔버스 dispose됨?

### 성능
- [ ] 불필요한 리렌더링 없음? (메모이제이션 확인)
- [ ] 장시간 세션에서 메모리 누수 위험?
