## 시안을 만든 방법

- 실제 앱(배포용 빌드, 3100번)을 Playwright로 띄우고, scene-0916의 9번째 프레임에서 차 `527702`를 골라 반려한 뒤, 그 화면
  위에 제안하는 UI를 DOM으로 그려 넣고 찍었다. 3D 화면, 사진, 썸네일, 목록, 타임라인은 실제 앱이 그린 것이다.
- **위에서 본 화면의 박스와 LiDAR 점은 실제 데이터다.** 임시 페이지 하나를 만들어 앱의 파서(`parseNuScenes`,
  `parseNuScenesPoints`)로 그 프레임을 읽어 그렸고, 그것을 화면 안에 끼워 넣었다. 손잡이, 원본 점선, 옮긴 박스는 그림이다.
  임시 페이지는 찍은 뒤 지웠고 저장소에 남아 있지 않다.
- 추천안 A의 그림에서 3D 화면이 좁아진 것은 실제다(칸의 폭을 바꾸면 같은 캔버스의 크기가 바뀐다).
- **그림이 보여 주지 못하는 것:** 박스를 고친 그림(4, 5, 6, 7, 10번)에서 3D 화면과 사진의 박스는 원래 자리 그대로다. 실제로는
  함께 움직인다.
- **예시 값:** 옮긴 거리 0.54m, 길이 +0.35m, 6°(그림을 위해 정한 변화), "In view 31 pts"(고치기 전의 28개는 실제로 센 값),
  연습 모드 그림의 1.31m / 0.12m / 0.04m / 1.5°.
