## 시안을 만든 방법

- 실제 앱(개발 서버, 3100번)을 띄우고, 그 화면 위에 제안하는 UI를 DOM으로 그려 넣고 찍었다. 3D 뷰, 사진, 박스, 목록은
  실제 앱이 그린 것이다. 저장소의 코드와 데이터는 바꾸지 않았다.
- 시안에 적힌 평가 숫자(주행 단위 표, 거리별 낮/밤, 1,452개 등)는 앱의 `evaluateFrames` / `evaluateScenes`로 저장소의
  404프레임을 실제로 계산한 값이다(설계 문서 2장).
- **예시 값:** `m5_sample_check.jpg`의 판정 숫자(5 / 5 / 2, "12 of 100 judged")와 목록의 판정 아이콘, 표본의 순서. 그림을 위해
  넣은 것이고 실제 판정이 아니다.
- `m3_iou05.jpg`는 `page.tsx`의 기준값을 잠깐 0.5로 바꿔 실제 화면을 찍은 것이다(찍은 뒤 되돌렸다). 위쪽 줄의 고르기 버튼과
  패널의 조건 한 줄만 그림이다.
