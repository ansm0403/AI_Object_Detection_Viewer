# F6 화면 기록 (시안과 캡처)

F6(카메라 6대)를 진행하면서 만든 시안과 실제 앱 캡처를 남긴다. 화면에 관한 결정을 무엇을 보고 내렸는지
나중에 확인하기 위한 기록이다. 설계는 [../../F6_six_cameras.md](../../F6_six_cameras.md)에 있다.

- 시각은 모두 **한국 시간(KST, UTC+9)** 이다.
- 캡처는 Playwright(Chromium, `--use-angle=swiftshader`)로 찍었다. 방법은 `../../HANDOFF.md` 8장.
- 원본 PNG를 1:1 크기 그대로 JPEG(품질 80)로 다시 저장했다. 지금까지 이미지 16장과 페이지 1개로 약 2.8MB다.
- 모든 화면은 **프레임 6**이다.
- 선택한 객체: 버스 `8a26f7…`(17m, 뒤 카메라와 오른쪽 뒤 카메라에 보임), 차 `527702…`(17m, 오른쪽 앞 카메라),
  차 `e3f3d9…`(35m, 앞 카메라에서는 오른쪽 끝에 잘려 놓침, 오른쪽 앞 카메라에서는 찾음).

## 보는 방법

| 페이지 | 내용 |
|---|---|
| **[compare.html](compare.html)** | 구현 **전**: "지금(F5 완료 화면) ↔ 시안"을 같은 자리에서 바꿔 본다. 설계 문서의 화면 결정(1~5, 7, 8)을 승인받을 때 쓴다. 조사 사진 3장도 여기서 본다 |

이미지를 클릭하거나 `Space`를 누르면 전환되고, 숫자키나 `←` `→`로 화면을 고른다. 이미지는 실제 크기(1:1)다.

## 2026-11-26_mockup — 화면 시안 (02:33~02:38 KST)

**실제 앱을 띄운 뒤 그 화면 위에 제안하는 UI를 그려 넣고 찍은 것**이다. 화면 틀, LiDAR 점, 3D 박스, 크기는 실제 앱의 것이다.

- **다른 카메라의 사진은 원본 nuScenes 사진**이고, 그 위의 정답 박스는 3D 박스를 그 카메라의 보정값으로 비춘 실제 값이다.
- **숫자는 모두 실제 값이다.** 이 컴퓨터에서 YOLOv8n(입력 1280)을 사진 60장에 돌린 결과를 설계 문서의 추천 규칙
  (사진 단위 채점, 점수 0.25 이상, 같은 클래스, IoU 0.3 이상, 가시성 0~40% 채점 제외, 거치대 규칙)으로 채점했다.
- **3D 박스의 색도 실제 장면에서 바꾼 것이다**(three.js의 개발 도구용 신호로 장면 객체를 얻어 선 색을 바꿨다).
- 그려 넣은 UI의 글자 폭과 칸 폭은 근사치다. 목록의 클래스 이름이 잘리는 것은 구현에서 칸 폭을 조정한다.
- 알려진 차이: `A2`(전체 보기)에서 선택한 박스를 3D 박스 모양으로 그렸는데, 실제 앱은 전체 보기에서 흰 사각형으로 그린다.
  평가 시안의 패널에서 화면 아래로 가려진 부분(클래스별 Recall의 일부, 안내 문단)은 고치지 않았다.
