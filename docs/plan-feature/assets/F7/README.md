## 시안을 만든 방법

- 실제 앱(배포용 빌드)을 띄우고, 데이터 요청을 가로채 nuScenes-mini의 다른 프레임과 장면을 **임시로** 끼워 넣었다
  (`page.route`). 저장소의 데이터 파일은 바꾸지 않았다.
- 그 화면 위에 제안하는 UI(타임라인, 장면 목록, 조건 줄, 결과 목록, 요약 패널)를 DOM으로 그려 넣고 찍었다.
  3D 뷰, 사진, 박스는 실제 앱이 그린 것이다.
- 시안에 적힌 숫자(조건에 맞는 프레임 수, 놓친 수 등)는 앱의 `parseNuScenes`와 `evaluateFrames`로 404개 프레임을
  실제로 계산한 값이다. 예외는 `m1`, `m2`의 **검수 진행(초록 막대, "214 / 2,424")으로, 예시 값**이다.
- `m5_*`는 그림이 아니라 실제 화면이다. 사진 파일만 줄인 것으로 바꿔 끼웠다(화면 배율 125%). 화질 비교가 흐려지지
  않도록 이 8장만 PNG로 두었다.
