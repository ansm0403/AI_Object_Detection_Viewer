# F4 화면 기록 (시안과 캡처)

F4(3D 박스 검수)를 진행하면서 만든 시안과 실제 앱 캡처를 남긴다. 화면에 관한 결정을 무엇을 보고 내렸는지
나중에 확인하기 위한 기록이다. 설계는 [../../F4_box_review.md](../../F4_box_review.md), 결과는
`.claude/docs/post-mvp-checklist.md`의 F4 완료 기록, 경계 사례는 `docs/edgecases/Edge_F#4.md`에 있다.

- 시각은 모두 **한국 시간(KST, UTC+9)** 이다.
- 캡처는 Playwright(Chromium, `--use-angle=swiftshader`)로 찍었다. 방법은 `../../HANDOFF.md` 8장.
- 용량을 줄이려고 원본 PNG를 1:1 크기 그대로 JPEG(품질 70)로 다시 저장했고, 창 크기는 사용자의 노트북 창에
  가까운 **1536×700을 기준**으로 남겼다(1280×720은 좁은 배치를 확인한 화면만). 전체 약 4.3MB, 34장.
- 선택 상태: 프레임 1의 보행자 `c8fcea…`(28m, 카메라에 보임), 카메라 밖 차 `34daad…`(22m),
  프레임 9의 차 `8fba98…`(28m, 카메라에 보임)을 주로 썼다.

## 2026-11-25_mockup — 화면 시안 (19:36~19:40 KST)

설계 문서의 화면 관련 결정을 보여주기 위한 시안이다. **실제 앱을 띄운 뒤 그 화면 위에 제안하는 UI를 그려 넣고
찍은 것**이라, 3D 뷰, 사진, 목록 내용, 색과 크기는 실제 앱의 것이다. 판정 상태와 진행률 숫자는 예시이고,
LiDAR 점 개수와 가려짐 단계는 nuScenes 원본의 실제 값이다. 카메라 칸의 선은 설계에서 제안한 방식(3D 박스의
꼭짓점 8개 투영)으로 실제 계산한 것이다.

**알아둘 것**
- B·C 단계 화면에는 그 뒤 단계에서 생긴 것(카메라 확대, 근거 한 줄, Export, Practice 버튼)이 없다. 당시의 기록이다.
- F4-F 뒤의 엣지 케이스 수정(상단 바 폭, 필터 안내 문구 등)은 캡처로 남기지 않았다. 내용은 `Edge_F#4.md`에 있다.
- 단계 확인은 캡처와 함께 스크립트로 했다(단계당 30~40항목). 스크립트는 임시 폴더에 두었고 저장소에는 없다.
