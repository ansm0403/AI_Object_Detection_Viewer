# F4 화면 기록 (시안과 캡처)

F4(3D 박스 검수)를 진행하면서 만든 시안과 실제 앱 캡처를 남긴다. 화면에 관한 결정을 무엇을 보고 내렸는지
나중에 확인하기 위한 기록이다. 설계는 [../../F4_box_review.md](../../F4_box_review.md)에 있다.

- 시각은 모두 **한국 시간(KST, UTC+9)** 이다.
- 캡처는 Playwright(Chromium, `--use-angle=swiftshader`)로 찍었다. 방법은 `../../HANDOFF.md` 8장.
- 용량을 줄이려고 원본 PNG를 1:1 크기 그대로 JPEG(품질 85)로 다시 저장했고, 창 크기와 상태의 조합 중 일부만 남겼다.
- **[compare.html](compare.html)** 을 브라우저로 열면 "지금 ↔ 시안"을 같은 자리에서 바꿔 볼 수 있다
  (이미지 클릭 또는 `Space`, 숫자키로 상태 전환).

## 2026-11-25_mockup — 화면 시안 (19:36~19:40 KST)

설계 문서의 화면 관련 결정(9, 11)을 보여주기 위한 시안이다. **실제 앱을 띄운 뒤 그 화면 위에 제안하는 UI를
그려 넣고 찍은 것**이라, 3D 뷰, 사진, 목록 내용, 색과 크기는 실제 앱의 것이다. 판정 상태와 진행률 숫자는
예시이고, LiDAR 점 개수와 가려짐 단계는 nuScenes 원본의 실제 값이다. 카메라 칸의 선은 설계에서 제안하는
방식(3D 박스의 꼭짓점 8개 투영)으로 실제 계산한 것이다.
