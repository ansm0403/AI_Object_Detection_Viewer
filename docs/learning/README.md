# 학습 노트 (Learning Notes)

이 폴더는 **본인을 위한 학습 저널**이다. 3D 시각화와 AI 데이터 도메인이 처음이라
코드를 읽는 것 자체가 학습이 되는 상황에서, "이때 내가 무엇을 이해했는가"를
Step 단위로 스냅샷처럼 남긴다.

설계/구현 정본은 별도다. 이 폴더는 정본이 아니다.

| 정본 위치 | 책임 |
|---|---|
| `.claude/docs/architecture.md` | 데이터 모델, 레이어 경계, 컴포넌트 계약 |
| `.claude/docs/mvp-checklist.md` | Step별 범위와 완료 조건 |
| `.claude/docs/domain-glossary.md` | Claude/협업자용 3D·AI 용어 정의 |
| `docs/PROJECT_DESIGN.md` | 프로젝트 전체 의도와 배경 |
| `docs/edgecases/` | 발견·해결한 엣지 케이스 이력 |
| **`docs/learning/` (이 폴더)** | **본인 학습 저널, 부패 허용** |

## 운영 원칙

1. **Step 단위 스냅샷.** 한 Step이 끝나면 그 시점 이해 수준을 `step-XX-<name>.md`
   한 파일에 박제한다. 이후 코드가 바뀌어도 옛 Step 파일은 원칙적으로 건드리지
   않는다 — 그 시점의 자기 이해를 보존하는 게 가치다.
2. **변경은 새 Step 파일에서 짚는다.** 예: Step 6에서 Step 4의 추정 로직이
   바뀌면, step-06 파일 상단에 "Step 4 노트의 X 부분은 더 이상 유효하지 않음"
   주석 한 줄을 둔다. 옛 파일을 고치며 다니지 않는다.
3. **부패해도 괜찮다.** 이 문서는 학습 흔적이지 시스템 진실이 아니다. 코드
   현재 상태가 필요하면 위 정본 표를 본다.
4. **링크 우선.** 코드 인용은 가능한 한 `[파일명](경로#L줄)` 링크로 처리한다.
   본문에 코드를 복붙하면 부패가 빨라진다.
5. **언어는 한국어 캐논.** 본인 학습용이므로 가독성 우선. 영어 변환은 하지
   않는다.
